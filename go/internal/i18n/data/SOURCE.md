# 繁体转换词表

来自 OpenCC（Apache-2.0），对应 `s2twp` 配置的转换链：

```
[STPhrases + STCharacters]  简 → 繁（词组优先，字符兜底）
TWPhrases                   台湾用词（软件→軟體、内存→記憶體、缓存→快取）
TWVariants                  台湾字形变体
```

**内嵌数据而不是依赖库**：这是一张表，不是一个算法。用 `go:embed` 带进二进制，
运行时零依赖；同时保住 `s2twp` 真正值钱的那部分——**词汇**转换，而不是逐字换形。
只换字的话「软件」会变成「軟件」而不是「軟體」，繁体版就失去意义了。

格式：`简体<TAB>繁体1 繁体2 ...`，取第一个候选。
更新方式：从 OpenCC 发行版复制同名文件覆盖即可，无需改代码。
